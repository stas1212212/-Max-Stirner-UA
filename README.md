## Прогрес

**1 із 5 нумерованих глав** має повний робочий переклад; вступ перекладено лише частково. Це **не** означає, що готово 20% тексту: глави різняться за обсягом.

Підрахунок слів запускається в GitHub Actions після змін перекладу, а також локально командою `python scripts/stats.py`.
